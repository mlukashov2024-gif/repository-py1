#  Лабораторні роботи з ООП (Об'єктно-орієнтоване програмування)

## Про репозиторій
Цей репозиторій створений для зберігання лабораторних та практичних робіт з дисципліни **«Об'єктно-орієнтоване програмування»**. 

Головна мета — освоєння базових та просунутих концепцій об'єктно-орієнтованого підходу, принципів SOLID, а також набуття практичних навичок проектування та розробки програмного забезпечення.

---

## План майбутніх робіт
1. Додати до репозиторію наступні лабораторні та практичні роботи з ООП.
2. Доповнити кожну роботу коротким описом завдання, використаних технологій і прикладами запуску.
3. Перевірити код робіт і додати тести для основних функцій та класів.
4. Оновлювати документацію та README після додавання нових матеріалів.
